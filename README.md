## Project Overview
This repository contains my lab setup, notes, and deliverables for Task 01 of the ApexPlanet Cybersecurity Internship. The objective was to build a functional, isolated hacking lab and practice foundational Linux, networking, and cryptography skills.

## Task 1 Highlights
*   **Isolated Lab:** Kali Linux (Attacker) and Metasploitable 2 (Target) on a private Host-Only network (`192.168.56.0/24`).
*   **Linux Fundamentals:** File navigation, permissions (`chmod`), ownership (`chown`), and package management (`apt`).
*   **Cryptography:** Symmetric encryption and hashing using OpenSSL (`AES-256-CBC`, `SHA256`).
*   **Tool Familiarization:** Nmap (port scanning), Wireshark (packet capture), Burp Suite (web proxy), and Netcat (network debugging).
